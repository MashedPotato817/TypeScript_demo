# 8 自由度机械臂运动学实验台

基于 TypeScript、Vite 与 Three.js 的本地交互 demo，对应参考案例中的 8 自由度串联机械臂：第 3 关节为移动副，其余为转动副。

## 启动

```powershell
cd 'C:\Users\Mashed Potato\Desktop\260916机器人技术基础(王振)\project\TypeScript_demo'
npm install
npm run dev
```

浏览器打开终端给出的本地地址。

## 功能

- 8 个关节滑块与实时正运动学、末端齐次变换矩阵
- **DH 局部坐标系动态可视化**：一键切换基座到末端各关节 $\{0\} \sim \{8\}$ 的局部坐标轴，直观印证 DH 建系与各转轴方向
- **教学实验面板（实验二 & 实验三）**：
  - 实验二：初始位姿（`init`）及 5 组目标位姿（`aid0` ~ `aid4`）快速选择与对比
  - 理论吻合校验：实时对比仿真齐次矩阵与教材标准值，计算位置与矩阵残差
  - 支持一键“载入理论正解”或“设为逆解目标点 (IK)”进行收敛验证
  - 实验三：一键运行 MATLAB 工具箱五段工件闭环规划轨迹及五目标巡检
- 以当前位姿为初值的阻尼最小二乘位置逆运动学
- 关节空间五次多项式（`jtraj` 原理）与三次多项式平滑插值
- 圆形、正方形、矩形、心形及实验三多段闭合末端轨迹；轨迹线严格由实际播放关节角的正运动学生成
- 带末端姿态锁定的六维阻尼最小二乘逆运动学，绘制过程中工具坐标系保持稳定
- 可旋转、缩放的三维教学骨架模型；点击地面可设置末端目标点
