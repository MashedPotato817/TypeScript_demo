# 8 自由度机械臂运动学实验台

基于 TypeScript、Vite 与 Three.js 的本地交互 demo，对应参考案例中的 8 自由度串联机械臂：第 3 关节为移动副，其余为转动副。

## 启动

```powershell
cd 'C:\Users\Mashed Potato\Desktop\260916机器人技术基础(王振)\project\TypeScript_demo'
npm install
npm run dev
```

浏览器打开终端给出的本地地址。

## 功能

- 8 个关节滑块与实时正运动学、末端齐次变换矩阵
- 以当前位姿为初值的阻尼最小二乘位置逆运动学
- 圆形、正方形、矩形、心形四种闭合末端轨迹；轨迹线严格由实际播放关节角的正运动学生成
- 带末端姿态锁定的六维阻尼最小二乘逆运动学，绘制过程中工具坐标系保持稳定
- 可旋转、缩放的三维教学骨架模型；点击地面可设置末端目标点

## 验证命令

```powershell
npm run test
npm run build
```

内部长度单位与参考案例保持一致；位置逆解仅约束末端位置，不约束姿态。
